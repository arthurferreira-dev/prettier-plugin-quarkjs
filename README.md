# Prettier Plugin to QuarkJS

This is a simple plugin to QuarkJS.

## How to use

Execute this row in your terminal:

```
npm i prettier-plugin-quarkjs
```

After, create a config file to Prettier (`.prettierrc`) and add this line:

```json
{ "plugins": ["prettier-plugin-quarkjs"] }
```

> [!IMPORTANT]  
> The plugin only works with you install and use the [VSIX file on the main repository](https://github.com/arthurferreira-dev/quarkjs/blob/main/jtx-language.vsix) on your VSCode.
